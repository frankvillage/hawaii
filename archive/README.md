# Archivio asset

Questa cartella conserva asset legacy rimossi dalla pubblicazione statica ma
non cancellati dal progetto.

- `media/hawaii/frames`: sequenza frame precedente, sostituita dai video MP4 e
  dalle still narrative correnti.
- `media/hawaii/legacy`: foto e loghi non referenziati dal sito.
- `static-defaults`: asset dimostrativi predefiniti di Next.js non utilizzati.

Gli asset possono essere ripristinati con un normale revert Git o spostandoli
nuovamente sotto `web/public`.
