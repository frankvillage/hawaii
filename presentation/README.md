# Hawaii Pescara 2026 Presentation

Deck modificabile preparato come base di presentazione per il cliente.

## File principali

- `src/hawaii_pescara_2026_presentation.js`: sorgente PptxGenJS del deck.
- `output/hawaii-pescara-2026-proposta.pptx`: file PowerPoint generato.
- `rendered/`: esportazioni PNG delle slide per revisione visiva.

## Comandi

- `npm run build:presentation`
- `npm run render:presentation`
- `npm run test:presentation`
- `npm run fonts:presentation`

## Nota

Alcune slide sono state impostate apposta come base da aggiornare dopo la riunione con il cliente, soprattutto su:

- offerta 2026
- servizi confermati
- menu e carta vini aggiornati
- peso relativo tra luxury e nightlife
- priorità commerciali e CTA
